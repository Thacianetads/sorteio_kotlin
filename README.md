# 🎲 App de Sorteio (Jetpack Compose)

Um aplicativo simples e intuitivo desenvolvido para Android em **Kotlin** utilizando **Jetpack Compose**. O aplicativo realiza o sorteio aleatório de 4 nomes a partir de uma lista pré-definida de participantes.

---

## 📱 Funcionalidades

- **Sorteio Aleatório:** Embaralha e seleciona 4 nomes da lista a cada clique no botão.
- **Interface Reativa:** Atualização instantânea da tela com o resultado utilizando gerenciamento de estado (`remember` e `mutableStateOf`).
- **Design Moderno:** Interface estilizada utilizando componentes do **Material Design 3**.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Componentes:** Material Design 3 (`Button`, `Text`, `Column`, etc.)
- **Ferramentas:** Android Studio
